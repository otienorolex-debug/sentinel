## 🔍 What It Does

Sentinel Link is an automated financial shield for digital marketing campaigns. It executes the following core operations directly inside the browser environment:

* **Audits Links in Bulk:** Takes large batches of active ad campaign URLs (from Google, Meta, or TikTok) and tests them simultaneously using non-blocking background workers.
* **Flags Broken Routes:** Instantly isolates dead pages (`404 Not Found`), server crashes (`500 Server Error`), and invalid destinations, labeling them with live green or red status badges.
* **Calculates Budget Leakage:** Multiplies detected link failure ratios against a company's real-world Cost-Per-Click (CPC) and daily traffic volume to display the exact financial loss in real time.
* **Bypasses Browser Security Barriers:** Seamlessly routes requests through a cloud proxy network (AllOrigins API) to check real-world external domains without triggering client-side browser CORS blocks.
